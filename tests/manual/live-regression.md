# 真實 Threads 重複驗證

本紀錄日期為 2026-09-20（Asia/Taipei）。互動測試使用 Codex 內建瀏覽器；自動化使用專案啟動的獨立 Chromium 暫存設定檔，兩者結果分開記錄。真實貼文可能變動或刪除，不能當作穩定的 CI fixture。

使用者後續改為優先使用本機 Chrome；新增的成功下載、主題及留言驗證另見 [本機 Chrome 紀錄](local-chrome-2026-09-20.md)，不覆寫本頁先前觀察。

## 開始前

1. 執行 `npm.cmd run verify`，記錄待測 build；版本仍為 5.2.2，單看版本號不足以區分本次未發布變更。
2. 在指定瀏覽器載入 `dist/chrome-extension`，完成內容處理同意。測 Chrome Extension 時停用同站的 Tampermonkey 版本。
3. 在真實貼文詳情確認媒體下載器含「只重試失敗項目」。修改 source 並 rebuild 後，需要重新載入擴充功能，再重新整理 Threads；本次只重新整理 Threads 仍執行舊程式。
4. 記錄測試前的語言、主題、四個功能開關及同意狀態，測試後還原。不要在測試中發文、回覆、按讚或分享。

## 可重複案例

| 案例 | 操作 | 預期結果 |
| --- | --- | --- |
| 混合輪播 | 開啟有圖片及影片的貼文，比對原生輪播與外掛清單 | 順序正確，影片封面不重複算圖片，貼文 ID 正確 |
| 空選取 | 不勾選任何項目，按下載已選取 | 顯示未選取提示，不建立下載任務 |
| 逐筆下載 | 勾一項或下載全部，等待完成 | 每項有成功／失敗／找不到媒體結果；摘要數字正確，沒有未替換的參數 |
| 失敗重試 | 在已有失敗結果時按只重試失敗項目 | 只重試失敗／找不到媒體項目；成功項目與未曾選取項目不重下 |
| 留言隔離 | 從母文進入一則文字留言的獨立詳情 | 清單為空，不混入母文媒體；複製內容及連結屬於該留言 |
| SPA 來回 | 從母文到留言，再返回母文 | 詳情只有一個下載器入口，清單與目前貼文一致，舊結果不串到新貼文 |
| 對話框鍵盤 | 開啟下載器，按 Esc，再開啟 | Esc 關閉後焦點返回入口；重複開啟沒有重複對話框 |
| 語言／主題 | 由設定切換語言與主題，再還原 | 外掛文案及圖示隨設定更新；明暗主題圖示可辨識 |
| 撤銷同意 | 開著下載器撤銷內容處理同意，切頁／重載，再明確重新啟用 | 按鈕與對話框清除，進階擷取註冊取消，撤銷狀態持續有效 |
| 剪貼簿內容 | 使用 [剪貼簿驗證頁](README.md) 原生貼上 | 正文、換行及去追蹤碼連結符合來源；成功提示本身不算內容核對通過 |

失敗重試要驗證「不重下成功項目」，必須先取得一份同時含成功及失敗的結果。全失敗只能驗證重試入口；不得把它記成成功／失敗混合重試通過。不要透過修改正式網站、權限或安全政策來製造失敗。

下載失敗時頁面警告包含 `download_failed`，後續 fallback 為 `media_request_unsupported`。這能證明失敗有逐筆呈現，尚不足以確認是內建瀏覽器能力、下載權限或 CDN 原因，也不代表已完成真實檔案下載。

2026-09-20 查核 [OpenAI 內建瀏覽器說明](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app)：產品支援一般檔案下載，但可受方案或工作區設定限制。這份文件沒有承諾完整支援 `chrome.downloads`；本次錯誤不能概括為「內建瀏覽器完全無法下載」，也不能只憑文件判定擴充功能下載應已成功。

測試找到摘要顯示 `找不到媒體 {not_found} 項` 的問題。根因是共用插值函式不接受含底線的參數名稱，已修改 `src/shared/i18n.js`，並加入 Chrome／Tampermonkey 的繁中及英文摘要回歸。修正後 `npm.cmd run verify` 的 252 項 Node 測試及兩平台生成檔檢查通過；獨立 Chromium 安裝測試 9／9 通過（29.3 秒），結果在 `artifacts/browser/report.json`。內建瀏覽器的修正複驗等待擴充功能重新載入。

本次修正後本機 `content.js` SHA-256：`287E91069E03B1189735AA90A55D8D25629F40BCC0AEC87ED9D1DE9AAE0CC829`。此值描述本機 build，不代表已核對內建瀏覽器所載入檔案的位元組。

先前曾在使用者 Chrome 取得單張 JPEG 下載；使用者指定改用內建瀏覽器後已停止操作該瀏覽器。該觀察不列入以上內建瀏覽器通過項目，也不取代新 build 的驗證。
