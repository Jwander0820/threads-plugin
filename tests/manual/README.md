# 可重複的剪貼簿人工驗證

此工具用來確認 Threads Plugin 複製到作業系統剪貼簿的實際文字。部分瀏覽器控制工具的虛擬剪貼簿與外掛實際寫入的剪貼簿可能分開；看到成功提示仍需透過原生貼上確認內容。

在專案根目錄啟動：

```powershell
node scripts/serve-manual-check.mjs
```

1. 在待測瀏覽器開啟 `http://127.0.0.1:4176/clipboard-check.html`。明確記錄使用 Codex 內建瀏覽器、Chrome Extension 或 Tampermonkey，避免混用不同環境的結果。
2. 在 Threads 的已知測試貼文點選擴充功能的複製文字或複製連結功能。
3. 切回驗證頁，點選「貼上測試內容」，使用原生 `Ctrl+V` 貼上。
4. 核對內容：文字應符合貼文正文，保留應有換行；連結應對應來源貼文，不夾帶其他文字。字元數只供檢視，以 Unicode code point 計數，包含換行。
5. 按「清除」後重複下一案例。記錄測試版本、平台、案例及結果，避免在公開紀錄保存私人貼文全文。
6. 測試完成後關閉頁面，在伺服器終端按 `Ctrl+C`。

頁面只有一個貼上欄位、即時字元數及清除按鈕。不會呼叫 Clipboard API，不會使用儲存空間或傳送輸入內容；重新整理、返回頁面或關閉分頁會清除欄位。伺服器只監聽 `127.0.0.1:4176`，僅提供 `/` 與 `/clipboard-check.html` 兩個固定路徑，不提供目錄瀏覽，也不接收表單資料。

這是可重複的人工驗證工具，不代表自動化已驗證系統剪貼簿，也不取代真實貼文與雙平台驗收。

真實貼文的重複驗證步驟及本次觀察見 [live-regression.md](live-regression.md)；可自動執行的安裝測試見 [../browser/README.md](../browser/README.md)。
